# Папка для изображений

## Требуемые изображения:

1. **product.jpg** - Фото продукта "Нежная кожа" (для карточки товара)
   - Рекомендуемый размер: 800x800px
   - Формат: JPG или PNG
   - Источник: https://drive.google.com/file/d/1Pnj5rP8POOWcQVWLtkrPYMEasSUorcIY/view

2. **header-image.jpg** - Изображение для шапки сайта (опционально)
   - Рекомендуемый размер: 1920x600px
   - Формат: JPG или PNG
   - Источник: https://drive.google.com/file/d/1JnE083dRZDgFiUmx1Q_M-HhANN75DKHc/view

## Как добавить:

1. Скачайте изображения по ссылкам выше
2. Переименуйте их согласно названиям выше
3. Поместите в эту папку (`public/images/`)
4. Закоммитьте и запушьте изменения:

```bash
git add public/images/
git commit -m "Add product images"
git push
```

## Оптимизация изображений (рекомендуется):

Перед загрузкой рекомендуется сжать изображения:
- Онлайн: https://tinypng.com или https://squoosh.app
- Или используйте любой другой оптимизатор изображений

Цель: файлы до 300-500KB для быстрой загрузки сайта.
