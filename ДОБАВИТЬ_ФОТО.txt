📸 ШАГ 1: Скачайте фото с Google Drive
─────────────────────────────────────

1️⃣ Фото продукта:
   Откройте: https://drive.google.com/file/d/1Pnj5rP8POOWcQVWLtkrPYMEasSUorcIY/view?usp=sharing
   Нажмите кнопку "⬇️ Скачать" в правом верхнем углу
   Сохраните файл

2️⃣ Фото для шапки:
   Откройте: https://drive.google.com/file/d/1JnE083dRZDgFiUmx1Q_M-HhANN75DKHc/view?usp=sharing
   Нажмите кнопку "⬇️ Скачать"
   Сохраните файл


📁 ШАГ 2: Переместите фото в проект
─────────────────────────────────────

Вариант А (Рекомендуется):
   Скопируйте скачанные файлы в папку:
   public/images/

   И переименуйте их:
   • Фото продукта → product.jpg
   • Фото шапки → header-image.jpg

Вариант Б (Через терминал):
   cp ~/Downloads/[имя_файла_продукта].jpg public/images/product.jpg
   cp ~/Downloads/[имя_файла_шапки].jpg public/images/header-image.jpg


🚀 ШАГ 3: Проверьте результат
─────────────────────────────────────

Если у вас запущен dev-сервер (npm run dev):
   • Сайт автоматически обновится
   • Откройте http://localhost:3000
   • Фото должны появиться на сайте

Если dev-сервер не запущен:
   npm run dev


💾 ШАГ 4: Сохраните изменения
─────────────────────────────────────

git add public/images/
git commit -m "Add product and header images"
git push


═══════════════════════════════════════════════════════════

❓ ПРОБЛЕМЫ?

• Фото не отображается → Проверьте название файла (должно быть точно product.jpg)
• Ошибка "файл не найден" → Убедитесь, что файл в папке public/images/
• Сайт не обновляется → Перезапустите dev-сервер (Ctrl+C, затем npm run dev)
